Things to use

Tools and utilities

  • ⭐ ColorSpace - Create colour palettes online.
  • ⭐ Cycle.Travel - A bicycle route planner built around quieter roads.
  • ⭐ Windy - Beautiful weather maps.
  • The Bike Market - A great tool for checking pricing on used motorcycles across the UK market.
  • Ninety 180 - Visualise post-Brexit EU stay days.
  • DiskPrices - Compare the cost of digital storage.
  • Radio Garden - Live radio stations from around the world.
  • Upscayl - Open source AI image upscaler.

Things to play with

  • ⭐ Lakera Agent Breaker - Teaches you to hack AI.
  • ⭐ Data Viz Project - A catalogue of visualisation types, useful when you know what you want to say but not what shape it should take.
  • ⭐ Learn Git Branching - Learn Git branching.
  • SQL Murder Mystery - Learn SQL by solving a murder.
  • Google Dataset Search - Search for datasets across the web.
  • ExplainShell - Paste in ugly SQL, get a breakdown of what every flag does.
  • W3Schools SQL Tutorial - Beginner SQL guide.
  • SQLFormat - Paste in ugly SQL, get tidy SQL back.
  • Mockaroo - Generate realistic synthetic data.
  • TableConvert - Convert tables between formats. CSV to Markdown, JSON to SQL, and most combinations you’d need.
  • Excel Practice Online - Free Excel exercises.
